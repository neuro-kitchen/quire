# Keys

The keys of `quire tui`. `?` shows the first table inside the program.

## Library

| Key | Action |
|---|---|
| `j` `k` `↓` `↑` | move |
| `g` `G` | top, bottom |
| `Ctrl-d` `Ctrl-u` | page down, up |
| `Tab` `h` `l` | switch pane |
| `Enter` | read the paper / open the project |
| `/` | filter (fuzzy, as you type) |
| `Ctrl-f` | search everything, papers' text too |
| `Esc` | clear the filter, close |
| `s` `S` | sort by the next column, reverse |
| `a` | add by DOI, arXiv ID, PMID or URL |
| `t` | toggle a tag by name |
| `1`–`9` | toggle a colored tag |
| `p` | get the PDF |
| `E` | extract the text again |
| `o` | open the PDF |
| `x` | move to the trash |
| `M` | merge a duplicate (`≈`) or mark it distinct |
| `e` `F` | edit in `$EDITOR`, refetch |
| `L` `U` | link to a project, unlink from this one |
| `X` | export this view (`.bib`, `.yml`, `.json` by the file name) |
| `Y` | copy the cite key |
| `m` | reading status: unread → reading → read |
| `w` | save the open search (shown in the left pane) |
| `J` | jobs running |
| `r` | reload |
| `?` | help |
| `q` | quit |

## Reader

| Key | Action |
|---|---|
| `→` `←` `l` `h` `Tab` | next, previous tab |
| `j` `k` `↓` `↑` | scroll |
| `Space` `b` (`PgDn` `PgUp`) | page down, up |
| `Ctrl-d` `Ctrl-u` | half a page down, up |
| `g` `G` | top, bottom |
| `t` | contents |
| `/` `n` `N` | search, next match, previous match |
| `f` | follow a figure or table mentioned in the text |
| `v` | select sentences to highlight (below) |
| `a` | write a note on the paper |
| `+` `-` | wider, narrower column |
| `J` `L` `T` | justified text, line spacing, colors |
| `R` | extract the text again |
| `q` `Esc` | back to the library |

## Selecting a passage (after `v`)

| Key | Action |
|---|---|
| `j` `k` | next, previous sentence |
| `l` `h` | longer, shorter selection |
| `m` | highlight |
| `c` | highlight with a comment |
| `x` | remove the highlight here |
| `Esc` | stop selecting |
